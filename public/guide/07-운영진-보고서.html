보고서 관리 (운영진)

활동 내역서 내려받기 · 대표자 서명.

부원이 쓴 보고서가 곧 학교 제출 문서입니다 부원이 아카이브 → 보고서 업로드에 쓴 내용이 학교 활동 내역서(HWP) 양식에 자동으로 채워집니다. 운영진은 내려받아 그대로 제출하면 됩니다.
① 부원이 보고서 작성내용·사진·참여자
② 대표자 서명 확인동아리 일정 설정 → 대표자 정보
③ 내려받기한 건씩(HWP) 또는 한 번에(ZIP)
④ 학교 제출그대로 제출

한 건씩 내려받기

보고서를 열면 제목 오른쪽에 HWP 추출 버튼이 있습니다. 누르면 그 보고서 한 건이 학교 양식 한글 파일로 내려옵니다.

  1. 아카이브 → 보고서 업로드에서 보고서를 엽니다 (관리자 페이지 → 보고서 관리에서 열어도 됩니다)
  2. 오른쪽 위 HWP 추출
  3. 파일명은 [팀명]_작성자_활동일.hwp 로 저장됩니다 (예: [QA스터디]_홍길동_261005.hwp)
버튼이 안 보이면 내려받기는 관리자·회장·부회장·서기만 할 수 있습니다. 다른 운영진 직책에는 버튼이 나타나지 않습니다.

한 번에 내려받기 (ZIP)

학기 말처럼 여러 건을 한꺼번에 제출할 때는 관리자 페이지 → 보고서 관리에서 묶어 받습니다. 화면에 보이는 목록이 그대로 ZIP 하나로 내려옵니다.

  1. 관리자 페이지 → 보고서 관리
  2. 기간(활동일 기준)과 검색(제목·작성자)으로 받을 보고서를 좁힙니다. 아무것도 안 걸면 전체입니다
  3. 오른쪽 위 일괄 다운로드 (N건) — N이 지금 목록에 걸린 보고서 수입니다
  4. ZIP 파일명은 보고서_기간_검색어.zip, 안에는 한 건씩 [팀명]_작성자_활동일.hwp 로 들어 있습니다
상황동작
목록이 0건버튼이 눌리지 않습니다
목록을 불러오는 중건수가 확정될 때까지 잠깁니다
300건이 넘음"기간이나 그룹을 좁혀 주세요" 안내가 뜨고 만들지 않습니다. 기간을 나눠 받으세요
일부 보고서를 못 만듦어떤 보고서가 문제인지 제목과 함께 알려 주고, ZIP은 만들지 않습니다. 해당 보고서를 고친 뒤 다시 받으세요
"팀으로 그룹핑"은 보기 방식만 바꿉니다 켜도 끄도 내려받는 내용은 같습니다. 기간·검색만 ZIP 에 영향을 줍니다.

양식에 들어가는 것

보고서 칸양식에서
스터디/프로젝트 명 · 작성자 · 시작일 · 활동 장소머리 부분에 그대로
활동 내용본문에 그대로
참여자 명단이름·학번·학과 표
활동 사진사진 칸에 원본 비율 그대로 칸을 꽉 채워 들어갑니다. 가로·세로 모두 됩니다
대표자 이름 · 서명맨 아래 "씨부엉 회장 ○○○" 옆에 서명 그림
스터디 후 느낀 점 · 다음 주 계획들어가지 않습니다 (홈페이지 안에서만)
고치면 다시 내려받으면 됩니다 파일은 내려받는 순간 만들어집니다. 부원이 보고서를 수정하거나 대표자 정보를 바꾸면, 다시 내려받은 파일에 반영됩니다. 이미 받아 둔 파일은 바뀌지 않습니다.

대표자 이름·서명

양식 맨 아래 회장 이름과 서명은 관리자 페이지 → 동아리 일정 설정 → 대표자 정보에서 가져옵니다. 회장이 바뀌면 여기서 바꿔야 모든 보고서에 새 이름·서명이 들어갑니다.

  1. 관리자 페이지 → 동아리 일정 설정
  2. 대표자 정보에서 이름을 적고 서명 이미지를 올립니다 (현재 서명이 아래에 보입니다)
  3. 저장 후 보고서를 하나 내려받아 맨 아래를 확인합니다
서명이 비어 있으면 양식에 들어 있던 예전 서명이 그대로 나갑니다 인수인계 직후에는 꼭 한 번 내려받아 이름과 서명이 바뀌었는지 보세요.

제출 전 확인

  • 맨 아래 회장 이름·서명이 지금 회장 것인지
  • 활동 사진이 사진 칸에 들어 있는지 (사진이 없는 보고서는 저장 자체가 안 되지만, 엉뚱한 사진이 올라온 경우가 있습니다)
  • 참여자 표에 빠진 사람이 없는지 — 빠졌으면 부원에게 보고서를 수정해 달라고 한 뒤 다시 내려받습니다
  • 기간으로 묶어 받았다면 ZIP 안 파일 수가 화면의 건수와 같은지
